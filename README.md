# Integral RH

Plataforma integral de recursos humanos con tres portales sobre una misma base:

- **Empresas**: solicitan servicios (selección, administración de personal, legal, contabilidad, coaching, psicología y medicina laboral), siguen sus búsquedas y revisan a los candidatos presentados.
- **Candidatos**: arman su perfil, se postulan a búsquedas abiertas y completan las evaluaciones (DISC y razonamiento).
- **Staff de Integral RH**: gestiona empresas, candidatos, procesos de selección, solicitudes y agenda.

Hecho con Next.js, TypeScript, Tailwind CSS y SQLite (Drizzle ORM).

## Puesta en marcha

Requiere Node.js 22 o superior.

```bash
npm install
npm run dev
```

La aplicación queda en http://localhost:3000.
